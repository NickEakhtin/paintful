# Конвейер оптимизации моделей

Все пути ниже — в этом репозитории (`tools/art/pipeline/` — эта папка, модели — `art/models/<имя>/`). Godot-скрипты запускать из корня проекта: `Godot --headless --path . --script res://tools/art/pipeline/<скрипт>.gd -- ...`.

1. `extract.py in.glb workdir [meshes]` — выгружает геометрию и текстуры high-poly модели.
2. `bake workdir <треугольников> <разрешение> <texW> <texH>` — упрощение (meshoptimizer), новая развёртка (xatlas), запекание цвета / нормалей / metal-rough с оригинала.
   Сборка: `g++ -O2 -std=c++17 -I<meshoptimizer>/src -I<xatlas>/source/xatlas bake.cpp <xatlas>/source/xatlas/xatlas.cpp <meshoptimizer>/build/release/libmeshoptimizer.a -lpthread -o bake`
3. `assemble.py workdir <разрешение> out.glb jpg Имя` — заполняет поля развёртки и собирает `.glb` (нормали PNG, остальное JPEG).
4. Опционально: `posmap.py` + `glow.py` (светящиеся стёкла), `flint.py` (кремень), `split.py` (разделение на объекты).
5. Превью: `nrender.py` (с картой нормалей), `scene_iso.py` / `iso_model.sh` (изометрия).
6. `mug.py out.glb [шероховатость]` — кружка: чистая low-poly сетка (960 треугольников) по профилю, снятому с оригинала, материал фарфор.
7. (Сначала `npm install` в этой папке.) `rodin_prop.sh in.glb out.glb имя seed доля_упрощения floor|wall` — модель из Rodin (base_basic_pbr.glb) в игровой пропс: сварка, упрощение, текстуры 1024, состаренная латунь и тёмная краска под палитру концептов (`age_brass.py`, цвета подгоняются автоматически), точка опоры (`pivot.mjs`: floor — центр основания, wall — низ задней стороны). `teximg.mjs` — достать/заменить текстуру в .glb.
8. `wall_panel.py концепт.png out.glb` — стеновая панель (обшивка) из фронтального концепта: молдинги собраны коробками по размерам с картинки (140 треугольников), сама картинка — текстура цвета, нормали сгенерированы из её деталей.
9. Люстра (светящиеся стёкла): Rodin отдаёт отдельный `texture_emissive.png`. `dumpuv.mjs` + `emclean.py` гасят свечение на треугольниках ближе заданного радиуса к оси (у люстры Rodin зажёг и верх колеса), `age_brass.py ... emissive.png` не трогает светящиеся тексели, `emissive.mjs` подключает карту свечения (KHR_materials_emissive_strength), `pivot.mjs ... ceiling` — точка опоры в потолочном креплении.
10. `brick_wall.py концепт.png out.glb` — кирпичная стена из фронтального концепта: по блоку на ряд кладки (контур ряда снят с картинки), выступающий карниз, концепт — текстура с обеих сторон. Размер модуля как у стены с обоями (2.6×1.9 м).
11. `plant_grade.py bc.png mr.png out_bc.jpg out_mr.jpg` — цветокоррекция растений из Rodin: листья / патина / медь / земля по оттенку и насыщенности подтягиваются к цветам концепта, медь становится металлом. (Для растений `age_brass.py` не годится — убивает зелень.)
12. `elevation.py` — общий модуль для пропсов из фронтальных концептов (блоки в пикселях концепта, сквозные проёмы, текстуры, запись .glb). `door_window_wall.py концепт.png out.glb` — стена комнаты с дверным проёмом и окном на нём (реальный масштаб: дверь 2.1 м).
13. `cabinet.py концепт.png out.glb` — шкаф со стеклянными дверями из отдельных объектов: body, door_left / door_right (начало координат на линии петель), drawer_left / drawer_right; стекло — отдельный прозрачный материал. Открывание — world/props/cabinet/cabinet.gd, сцена world/props/cabinet/cabinet.tscn.
14. `bake_scale.mjs in.glb out.glb коэффициент` — запекает реальный размер в модель (вершины и позиции частей), чтобы в Godot она стояла со Scale 1. Генераторы выше выдают модели в размере генератора — после них прогнать bake_scale с коэффициентом из MODELS.md (кроме cabinet.py и door_window_wall.py — они сразу в реальном размере).
15. Агентная генерация Rodin (`rodin_generate_agentic`, модель из сотен отдельных деталей без текстур): `wear_tex.py` — бесшовные текстуры износа (железо с медными царапинами, бронза с патиной; готовые лежат в `wear/`), `finalize_agentic.mjs in.glb out.glb высота доля_упрощения wear/` — склеивает детали по материалам (несколько вызовов отрисовки вместо сотен), упрощает, делает развёртку проекцией и накладывает износ на «enamel»/«bronze», переделывает стекло под Godot (полупрозрачное вместо transmission, с янтарным свечением), усиливает свечение нити, ставит опору в центр основания и реальную высоту.
16. `finalize_parts.mjs in.glb out.glb настройки.json` — то же для агентных моделей с **подвижными частями**: детали распределяются по группам (по имени и/или по положению), каждая группа — отдельный узел с началом координат на петлях / направляющей (например, дверцы и ящик), остальное — body; износ по материалам из настроек; можно перекрасить детали (`remat`). Пример — `station_cart.json` (запускать из корня репозитория). Текстуры износа — `wear/` (`wear_tex.py`: железо, бронза, краска по дереву, медь, медная столешница).
17. Открывающиеся дверцы у обычной (не агентной) генерации Rodin: генерировать шкаф **с открытыми дверцами** (концепт в открытом виде), затем `split_doors.mjs in.glb out.glb zFront xMin` — треугольники перед фасадом (z > zFront, |x| > xMin) становятся дверцами door_left / door_right, каждая поворачивается вокруг найденной петли в закрытое положение и растягивается до середины проёма. `place_root.mjs in out wall|floor` — ставит модель из нескольких узлов на пол / к стене, не трогая петли.
18. `tile_platform.py бесшовная_текстура.png out.glb [размер=2.0] [высота=0.1] [шаг_текстуры=1.0]` — платформа-плитка: квадратная коробка с повторяющейся текстурой сверху (боковины — чистая полоса той же текстуры). Бесшовная текстура вырезается из картинки ровно по целому числу периодов узора.
19. `rodin_to_godot.gd` — то же, что `rodin_prop.sh`, но только средствами Godot (без python и node): `Godot --headless --path . --script tools/art/pipeline/rodin_to_godot.gd -- in.glb out.glb Имя высота floor|wall|hinge_left|hinge_right [поворот°] [текстура_px]` — разворот лицом в +Z, реальный размер в вершинах, точка опоры, текстуры 1024 JPEG. Без упрощения и состаривания латуни — полигонаж задаётся сразу в Rodin (`quality_override`).
20. `cut_front.gd in.glb out.glb доля` — оставляет только переднюю часть модели (треугольники, целиком лежащие в заданной доле глубины от фасада +Z). Для случаев, когда Rodin сделал из секции забора замкнутое ограждение: `Godot --headless --path . --script tools/art/pipeline/cut_front.gd -- orig.glb cut.glb 0.11`, затем `rodin_to_godot.gd` на результат.
21. `rodin_optimize.gd` — тяжёлая модель Rodin из многих частей с общим набором текстур (например, 1 000 000 треугольников) → лёгкий пропс, только средствами Godot: части сливаются в одну сетку, упрощение встроенным генератором LOD (meshoptimizer) до заданного числа треугольников, реальная высота, опора в центре основания, текстуры 1024 JPEG, плюс отдельная карта свечения Rodin (`texture_emissive_*.png`): `Godot --headless --path . --script tools/art/pipeline/rodin_optimize.gd -- in.glb out.glb Имя высота треугольников [emissive.png] [яркость_свечения] [текстура_px]`.
