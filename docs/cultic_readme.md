# CULTIC

Проект Godot 4 с ассетами для игры: мебель, свет, модули стен и пола, 2D-персонаж с картой нормалей.

## Как открыть

1. Склонируйте репозиторий (или `git pull`, если он уже у вас).
2. Godot 4.3+ → **Import** → выберите `project.godot` в корне.
3. Главная сцена — `scenes/main.tscn`.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `models/` | Игровые модели `.glb` (упрощены до 400–10 000 треугольников, PBR-текстуры встроены) |
| `models/originals/` | Исходники из генератора (500 000 треугольников). Godot их не читает (`.gdignore`) |
| `scenes/CULTIC_ROOM_MAIN_SCENE.tscn` | Главная сцена (F5): тату-салон, собранный из моделей проекта в реальном масштабе. Генератор: `tools/room/build_my_room.gd` |
| `scenes/main.tscn` | Все объекты на одной сцене, разложены по группам `Models`, `WallKit`, `FloorKit` |
| `scripts/` | Скрипты игры: игрок, двери, свет, эффекты |
| `tools/pipeline/` | Скрипты конвейера: упрощение + новая UV-развёртка + запекание текстур (meshoptimizer, xatlas), свечение, кремень, превью |
| `MODELS.md` | Подробный список всех моделей: позиции, размеры, что с ними сделано |

## Заметки

- Все модели в реальном размере — в Godot ставятся со Scale 1.
- На сцене включены glow и SSR (отражения) — для светящихся стёкол фонаря и блеска пола/столешницы.
